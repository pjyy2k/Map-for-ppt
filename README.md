# Map for PPT

슬라이드에 넣을 지도를 만드는 **정적 웹 지도 편집기**입니다. 계정·백엔드·지도 API 키 없이 브라우저에서 동작합니다.

## 세 단계로 사용하기

1. **지역 선택** — 한국/세계 지도를 고르고 검색·체크박스·지도 클릭으로 지역을 선택합니다. 지역 옆 `›` 또는 지도 더블클릭으로 하위 행정구역을 탐색합니다.
2. **꾸미기** — 색칠·깃발·테두리 강조를 적용합니다. 지도 모양, 핀, 분리 지역 등의 상세 옵션은 접어 두어 필요할 때만 펼칩니다.
3. **다운로드** — 기본 PNG 버튼으로 바로 저장하거나, 펼침 메뉴에서 SVG·편집 가능한 PPTX·지역별 파일을 선택합니다.

섬·분리 지역 옵션은 현재 지도에 해당하는 항목만 표시합니다. 한국 지도에서는 알래스카·하와이 등을 숨기고, 미국 지도에서는 관련 옵션을 제공합니다. 숨김을 선택한 지역도 같은 지도 범위에서는 다시 켤 수 있습니다.

모바일은 지도 미리보기를 먼저 보여주고, 하단에 이전·다음 및 마지막 단계의 PNG 저장 버튼을 고정합니다. 터치 영역과 입력 글자 크기를 키우고 iPhone 하단 안전 영역을 반영했습니다.

단계를 바꿔도 지도 미리보기와 선택은 유지됩니다. 처음 접속할 때는 1단계만 표시합니다. 새 작업은 선택 지역 없이 시작하며 작업 내용은 브라우저에 자동 저장합니다. 상단 작업 관리 메뉴에서 JSON으로 저장·불러오기·초기화할 수 있습니다.

## 지도 범위와 표현

- 세계 지도: 대륙, 국가·지역, 국가별 1차 행정구역. 242개 국가·지역 피처와 원본 기준 4,596개 1차 행정구역을 포함합니다. 시도 단위 제공 여부는 국가마다 다릅니다.
- 한국 상세 지도: **17개 시도 → 252개 시군구 단위 → 3,555개 읍면동**, **2025-01-01 기준**. 일반구를 포함한 원본 시군구 코드 기준 개수입니다. 행정동 경계이며 **법정리 경계는 포함하지 않습니다**.
- 전체/지역별 강조 색상, 기본 육지·경계·배경색, 경계 두께, 지역 깃발 크기.
- 둥근/각진 모서리와 실시간 경계 단순화. 토폴로지의 공유 경계를 기준으로 단순화·곡선 보간합니다.
- 알래스카·하와이·그린란드·남극 표시/숨김, 미국 단독 지도에서 알래스카·하와이 삽입 지도.
- 가장 큰 육지만 표시, 작은 섬 생략 정도 조정. 군도 국가의 주요 섬도 생략될 수 있으므로 결과를 확인하세요.
- 제목, 선택 지역 이름, 범례, 확대·축소·이동 및 선택 지역에 맞춤.

## 핀 편집

꾸미기 단계의 **핀 추가와 편집**을 펼치고 `지도에 핀 찍기`를 누른 뒤 원하는 위치를 클릭합니다.

- 위치 핀·깃발·원, 크기·색상·테두리 조절.
- 드래그로 이동, 복제·삭제.
- 핀 선택 후 Ctrl/Cmd+C, Ctrl/Cmd+V로 앱 안에서 복사·붙여넣기. 텍스트 입력 중에는 해당 단축키를 가로채지 않습니다.
- 핀은 캔버스에 상대적인 위치로 저장합니다. 지도 범위나 확대율을 바꿔도 핀은 같은 캔버스 위치에 남습니다.
- 최대 200개. 핀과 지도는 작업 JSON에 함께 저장됩니다.

## 다운로드

| 형식 | 용도 |
| --- | --- |
| PNG | PPT에 바로 삽입. 가로 1920 / 3840 / 7680 px, 투명 또는 지정 배경 |
| SVG | 확대해도 선명한 벡터 지도. PowerPoint에서 그림을 도형으로 변환할 수 있음 |
| PPTX | 지역별 네이티브 자유형 도형, 텍스트, 핀 그룹을 포함. 이미지로 평탄화하지 않음 |
| 지역별 SVG ZIP | 선택 지역을 각각 별도 파일로 저장. 선택이 없으면 현재 범위 전체 |
| 지역 하나의 SVG | 목록에서 골라 해당 지역만 저장 |

캔버스 비율은 16:9 / 4:3 / 1:1입니다. 전체 SVG·PNG·PPTX에는 자유 배치 핀이 포함됩니다. 지역별 파일에는 해당 지역 도형과 지역 강조 깃발을 포함하며 자유 배치 핀은 포함하지 않습니다. PPTX에서 각 지역은 개별 도형이고, 핀은 지도와 분리된 그룹입니다. 그림 효과나 SVG 클리핑의 모든 세부 표현이 PPTX와 완전히 같지는 않을 수 있습니다. 지도 밖으로 과도하게 이동한 경우 저장 전에 맞춤을 권장합니다.

한국 상세 지도 파일에는 출처를 표시합니다. 글꼴은 별도 포함하지 않으므로 운영체제·PowerPoint 버전에 따라 글자 모양이 달라질 수 있습니다. 대형 PNG는 기기의 메모리에 따라 생성되지 않을 수 있으며 이 경우 해상도를 낮추거나 SVG/PPTX를 이용하세요.

## 30개 언어

언어 선택기는 **한국어를 항상 맨 위**에 표시합니다. 기본값은 한국어이고 이후에는 사용자의 선택을 브라우저에 기억합니다. 언어 변경 시 지도 선택·핀·스타일을 유지합니다. 아랍어·페르시아어·우르두어는 오른쪽에서 왼쪽으로 읽는 화면을 제공합니다.

한국어, English, 中文, Español, हिन्दी, العربية, Português, বাংলা, Русский, Français, اردو, Bahasa Indonesia, Deutsch, 日本語, Türkçe, Tiếng Việt, فارسی, Italiano, ไทย, Polski, Українська, Nederlands, Română, Ελληνικά, Magyar, Bahasa Melayu, Svenska, Dansk, Suomi, Čeština.

단계 안내·주요 설정·다운로드·상태 안내를 번역하며 국가·대륙명은 브라우저의 `Intl.DisplayNames`로 표시합니다. 한국 상세 지역 등의 고유 지명은 제공 데이터의 이름을 사용합니다. 번역 파일은 `public/locales/`에 포함하므로 운영 중 외부 번역 API를 호출하지 않습니다.

## 실행과 배포

배포할 파일은 모두 `public/` 안에 있습니다. 운영 시 npm 설치나 빌드가 필요하지 않습니다. 파일을 직접 더블클릭하는 `file://` 방식 대신 HTTP 서버로 실행하세요.

```bash
python3 -m http.server 8080 --directory public
```

`http://localhost:8080`에서 사용합니다.

### Coolify

- **Dockerfile 방식:** 저장소를 연결하고 Build Pack `Dockerfile`, Dockerfile `/Dockerfile`, 컨텍스트 루트(`/`), **Ports Exposes `80`**으로 지정합니다.
- **정적 호스팅 방식:** 빌드 명령 없이 게시 디렉터리를 **`public`**으로 설정합니다.
- 환경변수와 데이터베이스는 필요하지 않습니다. 모든 경로는 상대 경로입니다.
- JavaScript 모듈을 일반 `.js` 파일로 제공하므로 `.mjs`가 `application/octet-stream`으로 전달되는 정적 서버에서도 실행할 수 있습니다.

## 데이터와 라이선스

이 서비스는 발표용으로 단순화한 지도입니다. 최신 행정 개편·분쟁 관련 경계를 보증하지 않으며 공식 경계 확인용이 아닙니다. 일부 초소형 지역·섬을 생략할 수 있습니다.

### 세계 지도

[Natural Earth](https://www.naturalearthdata.com/)의 `ne_50m_admin_0_countries.geojson` 및 `ne_10m_admin_1_states_provinces.geojson`을 가공했습니다. Natural Earth 데이터는 [퍼블릭 도메인](https://www.naturalearthdata.com/about/terms-of-use/)입니다. 준비일·SHA-256·국가별 개수는 `public/data/manifest.json`에 기록했습니다.

### 한국 상세 지도

[통계청 SGIS](https://sgis.kostat.go.kr)가 공공누리 제1유형으로 공개한 행정동 경계를 [vuski/admdongkor](https://github.com/vuski/admdongkor)가 가공한 **ver20250101** 데이터를 추가로 단순화했습니다. 가공물 라이선스는 **CC BY 4.0**이며 SGIS 출처표시를 유지해야 합니다. 원본 조건은 `public/data/korea/LICENSE-DATA.txt`, 기준일·SHA-256·지역 목록은 `public/data/korea/index.json`에 포함했습니다. 해당 출처는 다운로드한 지도와 PPT 노트에도 표시합니다.

전체 배포 파일은 약 11 MB입니다. 읍면동·해외 시도 데이터는 필요한 지역만 추가로 읽습니다. D3, TopoJSON, JSZip의 라이선스는 `public/vendor/`에 포함했습니다.

## 개발과 검증

Node.js 22 이상을 권장합니다.

```bash
npm ci
npm run check
npm test
```

테스트는 데이터 수·계층·좌표 방향, 단계별 표시, 지역 선택·스타일, 실제 단순화와 모서리 처리, 핀 복제·단축키, 30개 언어 전환과 RTL, PNG 해상도·투명도, 개별 SVG ZIP, PPTX의 네이티브 도형과 핀 그룹, 작업 파일 검증을 포함합니다. DOM 테스트는 실제 브라우저 화면·다운로드 및 PowerPoint 앱 검증을 대체하지 않습니다.

지도 데이터 재생성:

```bash
npm run prepare-data -- /path/to/countries.geojson /path/to/admin1.geojson
npm run prepare-korea -- /path/to/HangJeongDong_ver20250101.geojson
npm run prepare-template
```

세계 원본은 [Natural Earth 저장소](https://github.com/nvkelso/natural-earth-vector/tree/master/geojson), 한국 원본은 [ver20250101](https://github.com/vuski/admdongkor/tree/master/ver20250101)에서 받습니다. 재생성 후 라이선스 파일·기준일·SHA-256을 확인하고 테스트하세요. UI 번역 원본은 `scripts/locale-rows.txt`, 운영용 언어 팩은 `public/locales/`입니다.

단순화 모드는 **동글게 / 각지게** 두 가지를 지원합니다. 두 모드 모두 경계 단순화 강도(0–100)를 적용하며, 공유 경계를 함께 처리합니다. 화면과 SVG·PNG·PPTX 내보내기에 같은 지도 형상을 사용합니다.

지역 선택은 드롭다운 없이 체크리스트로 통일했습니다. 세계 지도는 대륙 → 국가 → 시도/주, 한국 지도는 시도 → 시군구 → 읍면동 순서로 옆의 › 버튼을 눌러 탐색합니다. 체크박스는 강조할 지역을 선택하며, 목록 위 탐색 경로를 눌러 상위 목록으로 돌아갑니다. 지도 자체는 드래그로 움직이지 않고 핀만 드래그할 수 있습니다.

둥글게 모드에 둥글기 강도(0–100)를 추가했습니다. 핀을 끌면 출발점에 빈 원이 남고 이동한 핀까지 점선 경로가 표시됩니다. 마우스를 놓으면 “위치만 이동”과 “점선 경로 남기기”를 선택합니다. 취소하면 원래 위치로 돌아갑니다. 출발 원을 끌어 경로 시작점을 바꾸거나 “경로 지우기”로 없앨 수 있습니다. 경로는 작업 파일 및 PNG·SVG·편집 가능한 PPTX에 포함됩니다.

핀 경로는 출발 원과 핀을 잇는 비행 경로 형태의 곡선 점선으로 표시됩니다. 드래그 시 곡선이 갱신되며 PNG·SVG·PPTX에도 같은 곡선이 포함됩니다.

경로 색상은 지도 강조색과 독립적으로 설정할 수 있으며, 점선과 출발 원의 흰 테두리가 지도와 같은 색상 위에서도 경로를 구분해 줍니다.

핀 위에서 마우스 오른쪽 버튼을 누르면 해당 핀과 연결 경로만 삭제됩니다. 선택된 다른 핀과 지역 선택은 유지합니다. 모바일에서는 핀을 선택한 뒤 삭제 버튼을 사용합니다.

핀 삭제는 우클릭·삭제 버튼·Delete/Backspace 모두 확인창에서 확인한 경우에만 실행됩니다. 취소하면 핀과 경로를 유지합니다.

경로의 출발 원과 도착 핀 양쪽 모두 우클릭 삭제를 지원합니다. 선택하지 않은 출발 원도 우클릭할 수 있으며, 확인 후 해당 핀과 경로만 삭제합니다.

핀 드래그 작업은 마우스를 놓을 때 선택창에서 결정합니다. 위치만 이동을 고르면 기존 경로가 있는 경우 출발점도 함께 이동합니다. 경로의 출발 원을 직접 끄는 동작은 시작점만 조정합니다.
