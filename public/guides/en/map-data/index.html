Map sources, boundary dates and island options

Understand data licenses, simplified boundaries and remote region visibility.

  1. World boundaries are processed from Natural Earth, whose source data is public domain.
  2. Korean boundaries are based on Statistics Korea SGIS (KOGL Type 1), processed by vuski/admdongkor (CC BY 4.0), then simplified for this service. The Korean boundary reference date is 2025-01-01.
  3. Island and remote region options appear in Choose places when relevant to the displayed map. Adjust Alaska, Hawaii, Greenland, Antarctica and small island visibility where available.
  4. These are simplified presentation maps. Names and boundaries follow the source date; smoothing and island omission can change their appearance. Consult original data for official boundary questions.
