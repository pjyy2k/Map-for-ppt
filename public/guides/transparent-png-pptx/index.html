투명 PNG·SVG·편집 가능한 PPTX 지도 다운로드

슬라이드에 맞는 지도 파일 형식과 해상도를 선택하고 PowerPoint에서 사용하는 방법입니다.

  1. 다운로드 단계에서 슬라이드에 맞는 16:9·4:3·1:1 캔버스 비율을 선택합니다.
  2. 슬라이드 배경을 그대로 보이게 하려면 투명 배경을 켜고 PNG를 저장합니다. PNG 해상도는 1920·3840·7680 px 중 선택합니다.
  3. 크기를 바꾸어도 선명한 벡터 파일이 필요하면 SVG를 선택합니다. 선택 지역별 SVG ZIP과 지역 하나만 저장하는 기능도 있습니다.
  4. PowerPoint에서 지역·핀을 개별 도형으로 수정하려면 PPTX를 선택합니다. 작업을 나중에 이어가려면 작업 관리에서 JSON 작업 파일도 저장합니다.

자주 묻는 질문

PNG에서 지역 색을 PowerPoint로 개별 수정할 수 있나요?

PNG는 한 장의 이미지입니다. 지역과 핀을 별도 도형으로 편집하려면 편집 가능한 PPTX를 다운로드하세요.
